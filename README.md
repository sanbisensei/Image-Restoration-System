# Classical Digital Image Restoration & Deblurring System
**Course:** CSE 438 — Digital Image Processing  
**Implementation:** Pure Python 3 & NumPy (Zero Deep Learning, Zero AI)  
**Academic Rule:** All core restoration algorithms implemented from mathematical first principles.

---

## 1. Project Purpose & Academic Policy

This university course project investigates classical image degradation and restoration principles. In accordance with CSE 438 coursework guidelines:
- **No Deep Learning / Neural Networks:** We do NOT use neural networks, GANs, pretrained models, diffusion models, or cloud enhancement APIs.
- **Custom Implementations:** Core algorithms (2D spatial convolution, Gaussian noise, Salt-and-Pepper noise, Gaussian blur, directional motion blur, Mean filter, Gaussian filter, Median filter, 2D Discrete Fourier Transform visualization, Inverse filtering, Wiener filtering, PSNR, and SSIM) are implemented from mathematical first principles using **NumPy**.
- **Role of External Libraries:** OpenCV (`cv2`) is used strictly for file I/O (`imread`, `imwrite`) and color space conversion (`BGR <-> RGB`). Scikit-image is used strictly as an independent reference benchmark to cross-validate our custom SSIM implementation.
- **Honest Academic Reporting:** No fabricated ground-truth images or synthetic metrics are reported for real, unpaired vintage photographs.

## 3. Mathematical Foundations & Algorithms Implemented

### A. Custom 2D Spatial Convolution
- Discrete formula:
  $$(f * h)(x, y) = \sum_{s} \sum_{t} f(x - s, y - t) \cdot h(s, t)$$
- Flips kernel along both axes ($h(-s, -t)$) for true mathematical convolution.
- Boundary padding modes: `'reflect'` (mirroring), `'edge'` (replicate), and `'constant'` (zero-padding).
- Implemented using vectorized 2D slice accumulation in pure NumPy, avoiding slow 4-nested Python pixel loops.

### B. Degradation Simulator
1. **Additive Gaussian Noise:**
   $$g(x, y) = \text{clip}\Big(f(x, y) + \eta(x, y),\ 0,\ 1\Big), \quad \eta \sim \mathcal{N}(0, \sigma^2)$$
   Models thermal fluctuations in image sensor electronics.
2. **Salt-and-Pepper (Impulse) Noise:**
   $$g(x, y) = \begin{cases} 0 & \text{with probability } p \cdot (1 - \text{salt\_ratio}) \\ 1 & \text{with probability } p \cdot \text{salt\_ratio} \\ f(x, y) & \text{with probability } 1 - p \end{cases}$$
   Models ADC bit errors, dead/hot sensor pixels, and noisy communication channels.
3. **Gaussian Optical Blur:**
   $$h(x, y) = \frac{1}{2\pi \sigma^2} \exp\left(-\frac{x^2 + y^2}{2\sigma^2}\right)$$
   Normalized so $\sum h = 1.0$ (energy conservation). Models lens defocus and atmospheric turbulence.
4. **Directional Motion Blur:**
   Line Point Spread Function (PSF) along length $L$ at arbitrary angle $\theta \in [0^\circ, 360^\circ]$ using sub-pixel interpolation.

### C. Spatial Restoration Filters
1. **Mean (Box) Filter:**
   $$h(i, j) = \frac{1}{K^2}$$
   Reduces zero-mean noise variance by $K^2$. Limitation: blurs edges and turns impulse spikes into gray smudges.
2. **Gaussian Smoothing Filter:**
   Exponentially decays weights with distance from center, preserving edges more gracefully than a flat box filter.
3. **Median Filter:**
   Replaces center pixel with the statistical median of the $K \times K$ neighborhood.
   **Why it eliminates impulse noise:** Spikes ($0$ and $255$) are pushed to the outer ranks of the sorted neighborhood; as long as $<50\%$ of the neighborhood is corrupted, the median selects an uncorrupted neighboring pixel without smearing or creating artificial gray values.

### D. Frequency Domain Restoration
1. **2D Discrete Fourier Transform (DFT):**
   $$F(u, v) = \sum_{x=0}^{M-1} \sum_{y=0}^{N-1} f(x, y) e^{-j 2\pi (ux/M + vy/N)}$$
   Shifted to center DC component, compressed with $S(u, v) = \log(1 + |F(u, v)|)$.
2. **Point Spread Function (PSF) & Optical Transfer Function (OTF):**
   Circular center roll $(-K_h/2, -K_w/2)$ guarantees **zero spatial phase shift** upon frequency multiplication.
3. **Inverse Filtering:**
   $$\hat{F}(u, v) = \frac{G(u, v)}{H(u, v)} = F(u, v) + \frac{N(u, v)}{H(u, v)}$$
   *Failure Mode:* High frequencies where $H(u, v) \to 0$ cause noise $N(u, v)$ to divide by near-zero, blowing up into an overwhelming noise blizzard. Stabilized with thresholding ($|H| \ge \epsilon$).
4. **Wiener Filtering (Minimum Mean Square Error):**
   $$W(u, v) = \frac{H^*(u, v)}{|H(u, v)|^2 + K}$$
   $$\hat{F}(u, v) = W(u, v) \cdot G(u, v)$$
   The $+K$ parameter in the denominator prevents division by zero, smoothly attenuating noise at high frequencies while deblurring low frequencies.

### E. Evaluation Metrics
1. **Mean Squared Error (MSE) & Peak Signal-to-Noise Ratio (PSNR):**
   $$\text{PSNR} = 10 \cdot \log_{10}\left(\frac{\text{MAX}_I^2}{\text{MSE}}\right) \text{ dB}$$
2. **Structural Similarity Index (SSIM):**
   $$\text{SSIM}(x, y) = \frac{(2\mu_x \mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)}$$
   Implemented from scratch using an $11 \times 11$ Gaussian weighting window convolved in NumPy, benchmarked against `skimage.metrics.structural_similarity`.
3. **Execution Runtime:**
   High-precision CPU timing measured using `time.perf_counter()`.
